Aniket Bhati Portfolio

Files:
- index.html: the portfolio source code
- assets/preview.glb: the 3D avatar used by the page

To run:
1. Keep index.html and the assets folder together.
2. Open a terminal in this folder.
3. Run: python3 -m http.server 8000
4. Open http://localhost:8000 in your browser.

The page loads Three.js from jsDelivr, so an internet connection is needed.
