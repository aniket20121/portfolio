# Aniket Bhati — 3D Portfolio

A responsive neon portfolio with CSS 3D visuals, glowing effects, hover tilt interactions, project cards, responsive navigation, and scroll reveal animations.

## Files

- `index.html` — portfolio structure
- `style.css` — responsive visual design and 3D CSS effects
- `index.js` — navigation, reveal animations, and tilt interactions
- `music.html` — existing music experience

## Run locally

Open `index.html` in a browser or serve this folder with a static web server.

## Notes

Project images are loaded from Unsplash. Replace them with your own work images before production deployment.
